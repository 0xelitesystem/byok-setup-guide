# Common mistakes

Most BYOK trouble comes from a short list of avoidable mistakes. Knowing them in advance is most of the protection.

## Pasting a key into a public place

The top mistake by far is letting a key appear somewhere others can see it: a public post, a shared screenshot, a forum question, a synced public document. Always check that a key is not hiding in anything you share. If one ever does leak this way, cancel it immediately.

## Using one key everywhere

Sharing a single key across every tool means one compromised tool or one leak affects all of them. Make one key per tool so that any single problem stays contained to one key you can cancel on its own.

## Skipping the spending limit

Connecting a key without first setting a spending cap at the provider is how surprise bills happen. Set the cap before heavy use, not after. The cap is the difference between a bounded cost and an open one.

## Not copying the key at creation

Many providers show a new key in full only once. Forgetting to copy it is not a disaster, since you can cancel and remake it, but it is a small annoyance you can skip by copying it into your password manager the moment you create it.

## Leaving old keys active

Keys for tools you have stopped using sit there as risk with no benefit. Cancel a tool's key when you stop using the tool. A short map of which key is where makes this easy and keeps your account tidy.

## Storing keys in plain, unprotected places

A key in a plain notes app, an email to yourself, or a loose file is more exposed than it should be. A password manager is the right home for a key. The goal is that only you can reach it.

## Panicking instead of replacing

When something goes wrong with a key, the fix is almost always the same calm action: cancel the key and make a new one. Keys are replaceable by design. Treat a key problem as a quick swap, not a crisis.
