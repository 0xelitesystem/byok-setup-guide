# Storing keys safely

You do not need to be technical to store a key safely. You need a private place to keep it and the discipline to keep it out of public ones. This section is the practical how, for someone who does not code.

## Use a password manager

The best place for a key is a password manager, the same kind of app you use for website passwords. Save the key as a new entry, label it with the provider and the tool it is for, and let the manager encrypt and protect it. A password manager is built exactly for holding private strings like this, and it keeps the key off your notes app and out of plain files.

## If you do not have a password manager

If you are not using a password manager yet, this is a good reason to start. Until then, the key should at least live somewhere private and protected, not in a document that syncs publicly, not in an email to yourself, and not in a shared note. The bar is simple: could anyone but you reach this. If yes, it is the wrong place.

## Never put a key in a public place

Do not paste a key into a public message, a forum post, a screenshot you share, a public document, or anything that others can view. This is the single most common way keys leak. People often paste a whole screen to ask for help and do not notice the key is in it. Before you share any screen or text, check that no key is hiding in it.

## Be careful with screenshots and screen sharing

A key on your screen during a screen share or in a screenshot is a key you have shown to whoever is watching or whoever sees the image later. If you are sharing your screen, close anything showing a key first. If you are sending a screenshot, cover or crop any key in it. Treat a visible key the same as a visible card number.

## Replacing a leaked key is easy, so do it without hesitation

If you ever suspect a key has been seen by someone else, even by accident, cancel it at the provider and make a new one. This costs you nothing but a minute and removes the risk entirely. There is no reason to leave a possibly-exposed key active and hope. Cancel, replace, paste the new one into your tool, and move on.

## Keep a short list of where your keys are used

Keep a simple private note, ideally in your password manager, of which keys you have created and which tools each one is in. Not the keys themselves beyond the manager entry, just the map. When you stop using a tool, the map tells you which key to cancel. This small habit keeps your keys from piling up forgotten and active.
