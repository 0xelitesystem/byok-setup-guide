# BYOK Setup Guide

A plain-language guide to bring-your-own-key for people who do not write code. It explains what an API key is, where to get one, how to store it without leaking it, and how to keep costs from surprising you. If the phrase "paste your API key here" has ever stopped you cold, this guide is for you.

There is no programming in here. The goal is to make you comfortable getting a key, keeping it safe, and using it in tools that ask for one, while understanding what you are agreeing to and what it can cost.

## What BYOK means in practice

Many tools let you connect a provider, such as an AI model or a data service, by supplying your own key instead of paying the tool a markup. You sign up with the provider directly, get a key, and paste it into the tool. The tool then uses the provider on your behalf, and the provider bills you directly. You get provider pricing and control, in exchange for managing the key yourself. This guide is about doing that last part safely.
