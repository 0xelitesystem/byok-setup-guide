# Getting your first key

The steps to get a key are similar across providers, even though the exact screens differ. This is the general path. Expect to create an account, add a payment method, and generate a key from a settings area.

## The general steps

First, create an account with the provider whose service you want to use. Second, find the billing or payment section and add a payment method, because most providers require one before they will issue a usable key. Third, find the section called API keys, developer settings, or something similar. Fourth, create a new key. Fifth, copy the key immediately and store it safely, because many providers show a key in full only once at creation.

## Copy the key the moment you see it

When you create a key, the provider usually displays it once and then only shows a masked version afterward. Copy it right away and put it somewhere safe before you leave the page. If you miss this, you do not lose your account; you simply cancel the key you cannot see and create a fresh one. But it is easier to just copy it the first time.

## Name your keys if you can

Many providers let you label a key. Give each key a name that tells you where it is used, such as the name of the tool you will paste it into. Later, if you have several keys, the labels tell you which key belongs to which tool, so you can cancel one without breaking the others. A key named for its purpose is a key you can manage.

## Use one key per tool

When you connect more than one tool, make a separate key for each. It is a small amount of extra effort and it pays off: if one tool is compromised or you stop using it, you cancel only its key and the others keep working. One key shared across everything means one problem affects everything.

## Confirm it works, then stop touching it

After you paste a key into a tool and confirm the tool works, you are done with the key. You do not need to look at it again unless you are replacing it. The less a key moves around after setup, the less chance it has to leak. Set it, confirm it, and leave it.
